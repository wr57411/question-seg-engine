# 010 iPad 验收：截图审板 + 真机清单

**Blocked by**: 003, 004, 005, 006, 007, 008, 009

## 目标
把整条挑题链路按 iPad 820×1100 逐状态截图审板，并在真机 iPad Safari 上过一遍触控/键盘；
首项仍是内容齐全性（题号、题干、选项、答案、图与快照逐项对）。

## 涉及层
- [ ] 测试：截图脚本（可复用/扩展 `scripts/topic-shots.mjs`）覆盖：
  挑题开/关、选中高亮、两行托盘、`N·M` 角标、新建输入、同上题、撤销条、
  管理列表、删除确认、阅读模式详情、专题页类别筛选
- [ ] 量数：可点元素 ≥44px、题干字号 ≥13px、无横向溢出、托盘不遮挡选中题、角标不改变纸面几何
- [ ] 真机：iPad Safari 打开局域网 URL，检查点击 vs 滚动、键盘顶托盘、搜索、快速连点、
  刷新后数据仍在
- [ ] 回归：`npm run check` + `npm run audit:topic` 全绿

## 验收标准
- 截图 ≥8 张，存 `tmp/review-pick/`；每张可指认对应状态；无控制台异常
- 审板清单第一项是「内容齐全性」：至少抽 3 道已归类题，题干/选项/答案/图与快照逐项一致
- 真机清单逐项打勾并记录设备/系统/Safari 版本；发现的问题登记到 HANDOFF §6
- `npm run check` 与 `npm run audit:topic` 全绿；改动提交 main 本地（不推送）
