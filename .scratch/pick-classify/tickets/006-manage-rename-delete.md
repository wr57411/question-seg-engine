# 006 管理：改名 / 删除（影响题数）

**Blocked by**: 002, 003

## 目标
托盘「管理专题/类别」能改名、删除。改名按 id 更新，已归类题不受影响；删除先显示
「会影响 N 题」，二次确认后级联摘除；删除后角标、托盘、专题页统计同步。

## 涉及层
- [ ] 逻辑层：`renameTopic` / `renameCategory`（name 唯一、去空格）、`affectedCount`、
  `deleteTopic` / `deleteCategory`（级联 bindings + stale）
- [ ] 数据层：清单与所有卷 bindings 的原子更新；删除失败不落半截
- [ ] UI层：管理面板（两栏列表、使用题数、改名输入、保存、删除两步确认）
- [ ] 测试：`teach-store` 单测、写守卫、iPad 截图

## 验收标准
- 改名「基础」→「基础题」：所有已归类题的 chip 名称同步，角标不变；刷新后仍生效
- 改名成已存在的名字：拒绝并提示，不产生重名
- 删除「易错」（当前影响 2 题）：按钮显示「影响 2 题」，第一次点进入确认，第二次才删除
- 删除后：这两题的类别 chip 消失、角标 `M-1`；专题页该类别筛选项消失；业务标签不受影响
- 取消删除：数据不变
- 写入失败：清单与 bindings 保持原样并显示错误
- `npm run check` 全绿；截图：管理列表 + 删除确认
