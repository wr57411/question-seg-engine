# 005 托盘搜索

**Blocked by**: 002, 003

## 目标
专题/类别多起来后，一个搜索框同时过滤两行；点搜索结果直接归给当前题；搜不到时
能直接「新建『关键词』」并打上。

## 涉及层
- [ ] 逻辑层：`filterTeach(query, {topics,categories})` 纯函数（忽略大小写/首尾空格；
  中文标点按原样）
- [ ] UI层：托盘搜索框；两行同步过滤并显示命中数；无结果时显示
  「新建专题『xxx』」「新建类别『xxx』」两个入口；清空恢复完整列表
- [ ] 数据层：复用 002/003 的写通道
- [ ] 测试：`teach-store` 过滤单测 + iPad 截图 + 键盘态

## 验收标准
- 输入「平抛」：专题行只剩「平抛运动」，类别行无结果；点它即归给当前题
- 输入「易错」：类别行命中；点它即归给当前题
- 输入不存在的「磁场」：显示两个新建入口；点「新建类别」→ 建好并打上，搜索自动清空
- 清空搜索：两行恢复完整列表，最近顺序不变
- 搜索不会改变清单本身，也不产生写入
- `npm run check` 全绿；截图：命中态 + 无结果新建态
