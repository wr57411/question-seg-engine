# 004 同上题 + 撤销 + 写失败回滚

**Blocked by**: 002

## 目标
连续挑同一批题时，「同上题」把本会话最近一次已归类题的专题+类别整体复制到当前题（替换而非合并）；
每次 chip 操作可撤销；写入失败时 UI 回到写前状态并报错。

## 涉及层
- [ ] 逻辑层：`sameAsPrevious`（复制集合，替换当前归属）、动作快照 / `undoLast`、
  写入队列失败回滚
- [ ] UI层：托盘「同上题」按钮（无上一题或当前就是上一题时禁用）、5 秒撤销条、
  错误提示条
- [ ] 数据层：复用 002 的归属写通道；撤销是一次新的写入
- [ ] 测试：`teach-store` 单测 + 失败注入；iPad 截图

## 验收标准
- 题 A 归入「平抛运动 + 基础」；点题 B →「同上题」→ B 的角标立即 `1·1`，内容与 A 相同
- 若 B 原有其它专题/类别，「同上题」是**替换**而不是叠加；撤销后恢复 B 原样
- 撤销只回退最近一次动作；执行新动作后旧撤销入口失效
- 新建类别后撤销：只回退当前题的归属，不删除刚建的全局类别
- 模拟写入失败：chip 不保持点亮、角标不增加，页面显示「未能保存：…」
- `npm run check` 全绿；截图：同上题后 + 撤销条
