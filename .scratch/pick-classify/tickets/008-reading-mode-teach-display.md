# 008 阅读模式回显：淡角标 + 详情只读 + 去挑题

**Blocked by**: 002

## 目标
不开挑题模式时，也能看到归类结果：题号牌角标淡显；点题号牌打开详情，里面有只读的
「教学归类」区（专题 chips + 类别 chips）和「去挑题修改」；业务标签仍独立。

## 涉及层
- [ ] 数据层：只读 `teach` 数据，不新增写入
- [ ] 逻辑层：`assignmentFor` / `badgeCounts` 复用
- [ ] UI层：阅读模式角标透明度、详情面板「教学归类」区、「去挑题修改」按钮
  （进入挑题模式并选中该题）；业务标签区保持原样
- [ ] 纸面：`dimBadges` 在阅读模式生效；几何不变
- [ ] 测试：`layout-invariant`（淡显不改几何）+ iPad 截图

## 验收标准
- 阅读模式：已归类的题号牌显示 `N·M`，透明度约 0.55；未归类不显示
- 点题号牌：详情里出现「教学归类」，正确列出专题/类别；业务标签区仍显示原标签
- 点「去挑题修改」：切到挑题模式、托盘展开并选中该题，已归类 chips 高亮
- 阅读模式不能直接增删专题/类别（只能看）；业务标签仍可编辑
- 角标淡显 / 挑题模式清晰，两种状态纸面几何逐字节相同
- `npm run check` 全绿；截图：阅读模式淡角标 + 详情归类区
