# 011 自定义常用组合

**Blocked by**: 002

## 目标
把「当前题的专题+类别」存成一个**自己命名**的常用组合；下次在任意题上点组合名，一次套用。
不做「组合一/组合二」自动命名；名字必须由用户输入且可一眼认出。

## 涉及层
- [ ] 数据层：`data/out/teach/combos.json`（全局清单）；服务端 scope=combos，路径/形状/唯一性守卫
- [ ] 逻辑层：`final/teach-store.js` 的 `normalizeCombos` / `addCombo` / `comboMatches`；
  套用走 `sameAsPrevious`（替换当前题归属），复用撤销
- [ ] UI层：托盘标题栏**常驻组合条**（默认露 3 槽、12px 小字、超出横滑）；点 chip 即套用；
  「＋」起名小浮层；**长按 chip 380ms 拖动排序**并写回 combos.json；当前题无归类时 ＋ 禁用
- [ ] 测试：store/guard 单测；浏览器在**独立数据副本**上建组合/套用/撤销/刷新持久化

## 验收标准
- 当前题归入「曲线运动 + 基础」→ 组合浮层点「＋ 把当前题存为组合」→ 输入「曲线基础」→ 保存；
  `combos.json` 落盘，浮层出现「曲线基础 / 曲线运动 · 基础」
- 选另一道未归类题 → 点「曲线基础」→ 角标 `1·1`，归属与组合一致；撤销回到未归类
- 刷新后组合仍在；当前题与组合一致时该行高亮
- 同名组合拒绝并提示；空名字/空集合拒绝；组合里引用的专题/类别被删时，套用跳过并明说
- 组合浮层默认不占托盘高度；打开时列表可滚动、可点元素 ≥44px
- 测试只使用 `tmp/pick-test-app` 的独立数据副本，**不得写真实 `data/out/teach`**
