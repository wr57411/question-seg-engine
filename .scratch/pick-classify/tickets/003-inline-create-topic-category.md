# 003 内联新建专题/类别

**Blocked by**: 002

## 目标
挑题时突然想到新类别或新专题：托盘行尾点「＋」→ 输入名字 → 回车；永久进全局清单，
并立即打给当前题；重名不建重复项，直接选中已有并打上。键盘弹出时输入框不被挡住。

## 涉及层
- [ ] 数据层：`createTopic` / `createCategory`（服务端生成 id；name 去首尾空格后唯一）；
  写入 `data/out/teach/topics.json|categories.json`
- [ ] 逻辑层：`teach-store` 的新建与重名复用；创建 + 归属一次性提交；
  撤销只回退归属，不删除全局项
- [ ] UI层：两行各自的「＋」、单字段输入、`建好并打上`、创建后滚动到新 chip 并高亮；
  iPad 键盘用 `visualViewport`/CSS 变量抬升托盘
- [ ] 测试：`teach-store` 单测、写守卫、iPad 截图

## 验收标准
- 在类别行新建「易错」：立即出现在类别行并高亮，当前题角标 `M+1`；刷新后仍在
- 在专题行新建「力学综合」：立即打给当前题并角标 `N+1`；刷新后仍在
- 再建一次同名「易错」：清单不增加第二条，直接选中已有项并打给当前题
- 输入为空/只有空格：不创建、不写入，给出明确提示
- 新建时磁盘/网络失败：清单不出现幽灵项，UI 回到写前状态并报错
- iPad 上点「＋」弹键盘后，输入框与「建好并打上」仍可见可点
- `npm run check` 全绿；截图：新建输入态 + 创建后高亮
