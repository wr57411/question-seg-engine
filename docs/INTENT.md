## 一、用户与使用场景

- **称呼**：王先生；江西景德镇；**中文交流**（明确指令）。
- **用途**：教学 / 教辅。把纸质试卷、答案册变成可翻、可挑、可归类的电子题库。
- **真实使用设备 = 手机 / 平板，不是桌面**（2026-10-15 用户纠正：「这个主要是在手机或平板上使用」）。
  场景是「躺着 / 教室里翻」，诉求是「**用起来像原版书**」。⇒ 一切展示层交互先按触屏口径设计
  （无 hover、无右键、44px 触控目标、下半屏面板、服务必须打印局域网 IPv4）。桌面只是次要场景。
- **基准验收机型 = iPad 竖屏**；手机视口正文曾实测仅 5.67px（未闭合），真机 Safari 验收至今未做。
- **用户不读专业术语**（2026-11-13 原话：「我也看不懂你说的…专业术语太多」）。⇒ 汇报必须
  **大白话在前、专业版在后**；讲机制配真实截图或文本框图（先图→结论→机理）；技术选型由管家
  用客观实验拍板，不把术语抛给用户做选择题。

## 二、项目总目标（用户要的东西）

```
试卷 / 答案册 PDF
      │  解析后处理（本项目不做 OCR 引擎本身）
      ▼
结构化题目 JSON（题号/选项/答案/归属 正确、不丢内容）
      ├──► 成品页 / 阅读版：像原版书，手机/iPad 可翻
      └──► 挑题归类：专题 / 类别 / 业务标签 三套独立清单（题库/教辅侧）
```

- **不是**追求某个 OCR 模型最强；**是**追求「交付可信」：题切得对、答案配得对、页面看得清、内容不丢。
- 质量观：**宁可错拦不漏拦**；结构性异常（跳号/缺项/串行）先怀疑流水线，不先归因原书（`ATTRIBUTION.md`）。
- 验证观：**大规模验证必须机器做**，不接受「人逐页审核」当前提；**不用生成式大模型当裁判**；
  截图/像素域是最后裁判；「人工」指来源独立，不是人动手。

## 四、用户交代的不可违背约束（红线摘要，全文见 HANDOFF §5 / AGENTS.md）

- 不静默失败、不丢内容；丢弃/搬迁/改写前先回原卷页图核对，拿不准标 `needs_review`。
- 检测不改写；数据清洗须显式独立决策。
- `viewer/` `stages/` `final/` 只消费快照 JSON，不 import 引擎 `src/`。
- 纸面重建只 `stages/reconstruct.js` 的 `renderPaper` 一处实现。
- 判据与实现不同源；覆盖率分母须独立来源（原卷/OCR）。
- `0` 永远不是题号；启发式搬迁/丢弃取最严 AND + 同页守卫 + 可核对记录。
- `data/` 是快照不是事实（L7）；说「代码现在的行为」必须重跑。
- 判遮挡用墨迹口径（DOM 矩形高是字体盒不是墨迹）。
- 验证通过可**本地提交**；**禁 push** 除非用户发话。
- **不许再动 Clash Verge**（用户明确指令，网络问题已由其自行解决）。
- token 走环境变量不落文件；含明文 token 的 api 文档不提交。

## 五、沟通与工作方式交代（管家行为准则）

- 汇报**双版本**：大白话在前（档位=懂计算机但缺该子领域）、专业版在后。
- 讲下一步动作走 `socratic-explain`：一次一问、单条≤8行、讲一层就校验；用户说「直接说」才直给。
- 「背景」「路线图」= **出图订单**（文本框图/真实截图），不是纯文字。
- 技术选型**客观实验**定（量分布、对照、独立裁判），不拿术语让用户选；2026-11-13 起大部分技术拍板授权管家。
- 长程任务**全程管家主导**，用 `ROUTE-LEDGER.md` 的可验收子目标清单防遗忘、稳定完成。
- 下一步必须人工/外部状态改变时**暂停**，不烧 token 轮询；一次有界诊断+精确人工动作。
- 每批工作结束更新 `BACKLOG.md`；交接文档（HANDOFF）只在用户明确指令时维护。
- 回复「ok」= 按推荐执行；「2和3 ok」= 只做指定编号；建议须标「顺序清单」或「互斥选项」。
