## 1. 背景与目标

分支目标两条：① 内容识别源（已定 OXR，见 §6）；② **坐标方案**——墨迹匹配在「巨型条带」等干扰下失效，
需补充方案：把巨带识别出来 → 截出来 → 放进文本（**用户明确许可截图例外**）。
**最终验收：全册 ≥95% 的行坐标匹配是正确的。**

当前基线（L-11 快照，需实跑复核）：全册配带率 ~79%（剔网格页 82.4%）；最难的密集页 p76/p127 仅 ~59.5%。
注意「配带率」≠「坐标正确率」：noBand 行没有坐标 = 自动算错/缺。本方案同时抬覆盖与保精度。

## 2. 问题机理（为什么墨迹匹配做不了巨带）

墨迹配对（`scripts/ink-band-align.ts`）把 V3 行框吸附到「墨迹行带」（页图水平投影切出的真值几何）。
密集页里插图/表格与正文同 y 交错、墨迹竖直连通 ⇒ 投影切出 **巨带**（h>25pt，吞并多条原始墨行）。
一条巨带被 >3 条行框认领 ⇒ 容量守卫 `MAX_BAND_LINES=3` 按 DP 分截断，其余行降级 noBand（`norm=null`，丢坐标）。
豁免守卫（带高≤1.6×行高中位）**正确拒绝**巨带（太高）⇒ 巨带行无法靠豁免救回（B-38 小试已证）。

四分类（`audit-gap-roots.ts`，判据 import 不重写）：singleLineMultiBox（h≤12pt）/ zeroGap（runs=1）/
figureGiant（runs>1 且 h>25pt）/ formulaSmallGap（其余）。p76/p127 合计 figureGiant 截断行 113/175，是最大头。

## 3. 关键实测发现（推翻原前置，2026-11-13）

原 B-38 设想「先做插图框检测 → 专属切带」。**实测推翻这条前置**：

- **巨带内被截断行的 V3 框本身已是紧单行框**（h≈medH）。例 p076_g0「1.A【解析】本题考查波的传播.根」
  V3 框高 10.7pt（medH=10），p076_g3=9.3pt、g5=9.4pt。这些行 noBand 的根因是「墨迹巨带+容量截断」，
  **不是 V3 框跑偏**。⇒ 回退坐标可直接用 V3 框，无需插图框检测/重切带。
- **inkExtent 扩窗精修会吞邻行**（事故）：最初用「V3 框扩窗后取墨迹外接」精修，p076_g0 被扩成 33pt 三行
  （裁图实证：header+本行+下行）。密集区行距 < 扩窗量 ⇒ 外接框吞邻行。**禁用扩窗精修，回退坐标=V3 框本身。**
  修正后机器全量统计：两页「过高(>2×medH)框」=0（多行吞并消除）。

## 4. 方案架构

```
V3 行框 ──墨迹配对──> 配上：坐标=墨迹带真值（coordSource:"ink"）
                  └─ 截断/noBand ──裁图回退──> 坐标=V3 框本身（coordSource:"crop"）
                                              └─ pdftoppm 裁图 ──> 本地 PP-OCRv5 复核（独立金标）
                                              └─ 成品页：截图例外放置（用户许可）
```

- **检测器**：生产带 h + 吞并 minGapPx=0 原始墨行 runs → 四分类（已实现于 `audit-giant-crop.ts`，
  独立复现 L-14：p76 figureGiant 受害 42≈43、p127 71≈70）。
- **回退**：对截断行保留 V3 框坐标 + 裁图。默认仅 figureGiant；`--all-noband` 扩到全部截断行（实测更优，见 §5）。
- **复核**：裁图交本地 4070 PP-OCRv5 重读 → 与 V3 文本字符相似 ≥ 阈值 ⇒ 坐标正确（独立来源，R3）。
  复用 L-12 资产 `hole-read-export.ts`/`hole-read-judge.ts`（judgeHole 真 import）。
- **生产集成（B-39，待拍板）**：`alignLinesToBands` 增旗标 `truncationCropFallback`（默认关=逐字节不变），
  截断行保留 V3 norm + 标 `coordSource:"crop"`（输出行新增可选字段）；下游裁图复核 + renderPaper 截图例外放置。

## 7. 验收口径（95% 怎么量）

- **分母**：全部 V3 检出的文本行（独立于配对器——V3 是另一来源，满足「分母须独立」红线）。
- **正确**：该行被指派的框（墨迹带 或 回退 V3 框）在页图上紧包且仅包该行文字。
- **金标 oracle**：独立 rec（本地 PP-OCRv5）重读裁图 → 与 V3 文本字符相似 ≥ 阈值 ⇒ 正确；辅以裁图目视抽样。
- **机器代理（无笔记本时的保守下界）**：单行高区间 + 框内有墨（误标分式/短标签，偏低）。
- **目标**：correct / 全部 V3 行 ≥ 95%。密集页代理已达 95.8–98.2%；全册待测。
