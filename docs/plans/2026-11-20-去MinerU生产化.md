# 去 MinerU 生产化（no-MinerU）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **执行方式（用户已指定）**：workflow_tool MCP 长程工作流，用户不在场全程自主决策；节点=本文 M1–M6，hole 按最新发现动态续写；不含需用户插手/反复迭代步骤。

**Goal:** 生产链彻底移除 MinerU——读字/骨架/表格/坐标全部换独立源（OXR 内容 + V3 结构/行框 + 墨迹坐标真值 + 页图裁图兜底），坐标正确率保持 ≥95%。

**Architecture:** 导出器 `export-stages.ts` 骨架=喂入的 layout.json（argv[3]），源无关；把生产输入从 MinerU layout 改喂 OXR layout。OXR 读表为 0 ⇒ 表区域改由 V3 检测**插入**（现 applyTableV3 是覆盖 MinerU 表块）；OXR/MinerU 共有的 markdown 图片漏泄行 ⇒ 页图裁图兜底。巨带补行 attachGiantCropVictims 判据（文本包含+四边近等）本源无关，换骨架后自动作用于 OXR 行。

**Tech Stack:** TypeScript ESM + node:test，零运行时依赖；ffmpeg 裁图；本地 4070 PP-StructureV3（笔记本 ssh laptop）；OXR layout 快照。

**Spec:** `docs/branches/tool-no-mineru.md`（分支总目标=替换 MinerU）+ `docs/ROUTE-LEDGER.md` + 本文节点子目标。

## Global Constraints

- 不静默失败、不丢内容：丢弃/搬迁/改写前先回原卷页图核对；拿不准标 needs_review；原文保留快照/title。
- 检测不改写；判据与实现不同源；覆盖率分母须独立来源（V3 行/原卷）。
- viewer/stages/final 不 import src/；纸面重建只 stages/reconstruct.js renderPaper 一处。
- 纯逻辑展示层 .js 用 @ts-check+JSDoc 不手写 .d.ts；DOM 类不写 @ts-check。
- 动手前 `npm install && npm run check` 全绿 + `npm run preflight`；Stop hook 凭证 tmp/.check-stamp 别手改。
- data/ 是快照不是事实（L7）；查配对用 `npm run diag:match`，禁自写临时脚本重算几何判据（B-35）。
- 裁图用 ffmpeg -vf crop 不用 sips；SSH 远程用落盘脚本不用 python -c 内联（L13）；笔记本 Windows cmd.exe 语法；jobs 必须传 --pages 显式页清单（L12）。
- 严格 TDD 红→绿→真跑；验证通过直接本地提交禁 push；大规模验证机器做不用生成式大模型当裁判。
- 用户不在场：可逆细节自决；硬件不在线 ⇒ 该节点记 notCovered 继续，不硬阻塞、不轮询重试。
- 共享 worktree 并发：编辑前 git status/diff HEAD 核对，提交只 add 精确路径。

## Review Focus

- OXR 骨架缺表块 ⇒ 表区域整段消失（输入类：含表页）；期望 V3 插入表块后结构/图/文齐全，不丢表。
- markdown 漏泄行被当正文渲染 ⇒ 网址文字上页（输入类：`![…](http…` 行）；期望改贴原卷小图、原文留 title。
- 插入表块与漏泄行叠印双像（输入类：表区内的 markdown 行）；期望 coveredByTable 抑制、单印。
- 换骨架后巨带补行挂接失败 ⇒ 坐标回退丢失（输入类：截断巨带行）；期望 attached>0 且复测 ≥95%。
- 插入表块破坏阅读顺序/题号（输入类：page.order）；期望 order 按 y 插槽、题号不串。
