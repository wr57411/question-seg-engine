# 方案 · V3 行框↔墨迹对齐：几何换源（2026-11-07）

> **状态（2026-11-07 终局）**：Loop 已关闭——目标修订为可达终态「配带率 **93.9%** + 洞配对 **13/14** + 8 条补字（0 错配）」，
> 实验形态 14/14 几何满配挂 `--experimental-align`（与语义干净不可兼得，四轮实测）。复开条件与全部数据见 `DECISIONS §110`，
> 接续工作项 = **BACKLOG B-36**。

> **目标（用户 2026-11-07 拍板）**：V3 产生的文本框跟墨迹进行配对，比率尽可能提高，目标 100%。
> 允许改良算法，也允许不用算法的办法。
>
> **一句话结论**：V3 行框几何质量差是根因（对齐率仅 25.3%，偏移 −16～+13pt 逐行乱跳、x 也偏），
> **校准它不如换掉它**——用墨迹切行带当真值几何（0 偏移），V3 行框只贡献**文本**，
> 配带成功后几何整体替换为墨迹带。这既是「改良算法」，也是「不用算法的办法」（几何换源）。

## 1. 基线（`scripts/audit-line-align.ts`，4 页 541 行框，零 API）

| 指标 | 数值 |
|---|---|
| 对齐率（\|dy\|≤2pt） | **25.3%** |
| \|dy\|≤5pt | 49.9% |
| \|dy\|≤8pt | 69.1% |
| >8pt | 130 条（24%） |
| 无带可配（noBand） | 37 条（6.8%） |

大偏移分解：半行距（±9.5pt）偏移 ×101、错一行 ×24、错两行 ×5。
逐页偏移**无系统性**（同页 −13～+16pt 乱跳、x 方向也有偏 30pt+ 的框）⇒ V3 行框位置**不可校准**，只能替换。

## 2. 方案：几何换源（墨迹带为真值）

```
V3 文本行(文本可信、几何不可信)
   │ ① 按栏切墨迹行带（splitInkLines，真值几何，已有实现+单测）
   ▼
墨迹行带序列（每栏一组，0 偏移）
   │ ② V3 行框 → 墨迹带 配对（同栏 + 重叠打分 + 容量守卫 + 冲突不猜）
   ▼
对齐后的行（文本=V3，几何=墨迹带）
   │ ③ matchLinesToHoles 行侧中心 = 墨迹带中心（真值）
   ▼
行↔洞配对（dy 天然归真；横向交集用墨迹带 x 范围=真值）
```

- **打分**：y 重叠为主、带中心距加权；「半行距偏移」×101 条靠「重叠 + 中心距」双打分可救
- **容量守卫**（B-32 哲学复用）：一条墨迹带被多条 V3 框搭 → 按重叠排序取最优、其余记冲突不猜
- **不猜原则**：无带可配（37 条）与严重歧义 → 显式 `needs_review`，不硬配
- **回滚**：注入点不传对齐几何 → 旧行为逐字节回来

## 3. 预期与「100%」的诚实评估

- **几何配对层可逼近上限**：配带成功后行侧中心=墨迹真值，行↔洞的 dy 判据天然满足；
  p159 h0 类「横向不重叠」也消解（墨迹带 x 范围=真实墨迹 x）
- **两块救不了**（判据层无解，如实声明）：
  1. **上游漏读**：V3 没读出文本的行（洞有墨迹无候选）——只能标「无行压中」，100% 需补 OCR 通道
  2. **错两行/无带**的极差框（~42 条/541，7.8%）——显式标 needs_review，不硬配
- **诚实口径**：几何层 100% = 「有 V3 文本的行全部对齐墨迹」；端到端「洞全覆盖」还差上游漏读，
  那是 B-28「接线条件重写」的范畴（有效补字口径），不是配对算法问题

**终态**：

- 实验路径 = DP 换源（`ink-band-align.ts` + `--experimental-align` 默认关）：**配带率 93.9%**（基线 25.3%）
