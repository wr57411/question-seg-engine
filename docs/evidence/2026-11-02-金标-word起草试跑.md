# 金标准「Word 起草 + 分歧看图」试跑（2026-11-02）

**要回答的问题**：`BACKLOG B-08` 说 13 本 / 1,086 题只转写了 39 题。能不能用
`books/物理_教材基础练.docx`（夸克扫描王的真文字）**自动起草**金标准，只把分歧题交给人看图，
从而把整本金标做起来？

**样本**：《物理_教材基础练 电路》引擎产物 31 题（2026-11-02 实跑）。
**方法**：`tmp/gold-draft/draft.ts` —— Word 段区间用 `教材知识N` 锚点定（与 `npm run audit:anchor` 同源），
比对用 `§99 v2` 的**汉字 4 字窗覆盖率**（公式/字母写法必然不同，只拿汉字窗比）：
≥90% 判「可起草」、50–90% 判「需看图」、<50% 判「Word 没有」。

## 结果

| 分类 | 题数 | 说明 |
|---|---:|---|
| 可起草（≥90%） | **18** | 题号、出处标注、文字、选项行都能从 Word 取 |
| 需看图（50–90%） | 10 | 见下方成因分析 |
| Word 没有（<50%） | 3 | 实为**切块判据问题**，不是 Word 缺内容（见发现 2） |
| Word 有、引擎未认领 | 1 | 待核 |

## 发现 1（决定性）：Word 起草的文本**一条公式都没有**

```
电路 31 题里含公式的        24 题   （引擎题干有 $...$ / \frac / \mathrm …）
18 条起草结果里含公式的       0 条
被起草的题中原本含公式的      19 题  ⇒ 这 19 题的起草文本必然缺公式
```

夸克 Word 把**公式存成图片**，所以 Word 只能给出「文字骨架」。而金标准要的是**完整题干**——
物理题的公式就是题干本身。⇒ **Word 起草省不掉看图**，只能把「整题抄」降成「补公式/补图」。

## 发现 2：三道「Word 没有」是我切块切错了，不是 Word 缺

```
Word 里「教材实验 10–13」确实存在：段 3871 / 3905 / 3940 / 3963（电路区间 3668..4116 之内）
但 `教材实验 N` 不是题号行 ⇒ 被切成一堆 `1.` `2.` 子项条目，匹配时覆盖率只剩 1–3%
且 Word 侧「实验10」整段只有 876 字，引擎题干 3163 字（公式/图都是图片）
```

⇒ 若要起草实验块，得先按 `教材实验 N` 起块；但公式缺失问题依旧。

## 发现 3：覆盖率低**不能直接判谁错**（抽样两例）

```
p0 #2   引擎 175 字 vs Word 235 字
        Word 多出选项与页脚噪声「上课认真听 下课练天星 107 变式2 电阻定律及欧姆定律」
p12 #6  引擎 780 字 vs Word 515 字
        Word 缺公式与图（题干里的 $I_0$、$U_0$ 等在 Word 里是图片）
```

一边是 Word 更长（噪声/选项混进条目），一边是引擎更长（Word 缺内容）——
**同一个「REVIEW」标签下有两种相反的原因**，所以覆盖率只能当分诊，不能当结论。

## 结论

1. **能省的**：从空白到骨架（题号、出处标注、纯文字部分、选项行）——样本里 18/31 可直接预填。
2. **省不掉的**：公式与图。样本里 24/31 题含公式，这些必须回原卷页图，**Word 代替不了**。
3. 所以这条流水线的正确定位是**预填器**，不是「免人工金标」。它把每题的工作量从
   「整题抄」降到「对着页图补公式/补图」，但**看图这一步一题都省不掉**。
4. `gold/README.md` 的硬要求仍然成立：标签必须回原卷页图，不能从系统产物复制；
   Word 是**独立第二意见**（可用来发现漏题），不是真值。
5. 起草结果写在 `tmp/gold-draft/电路.draft.json`，**未进 `gold/`** —— 缺公式的文本不能当标准答案。

## 复现

```bash

node --import tsx tmp/gold-draft/probe.ts                          # 公式缺失 / 实验块 / 抽样对照
```
