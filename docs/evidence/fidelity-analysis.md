## Q4 分开「字号估错」与「字体度量不同」

`F_w = bbox宽px / Σem`（宽度隐含字号）；`F = 现行高度隐含字号`。**注意 `F_w/F ≡ 1/(Q3 比值)`，两者是同一个量的倒数**，不是独立证据。

| 分组 | n | p10 | 中位 | p90 | p99 | >1.2 占比 |
|---|---|---|---|---|---|---|
| 全部 | 964 | 0.97 | **1.44** | 1.70 | 5.73 | 775 / 964 = 80.4% |
| **严格正文（纯 CJK）** | 77 | 1.12 | **1.31** | 1.55 | — | — |
| 正文（含 CJK 无公式） | 769 | 1.25 | 1.47 | 1.70 | — | — |
| 含 ASCII 字母数字 | 683 | 0.87 | 1.44 | 1.66 | — | — |
| 含公式标记 | 176 | 0.60 | 0.99 | 1.29 | — | — |

**解释（决定性证据在纯 CJK）**：CJK 字符在任何字体、任何引擎里都是 **1em 宽**（全角是字体设计定义），所以对纯 CJK 行，「1.00em/CJK」的度量**同时精确描述原卷印刷体和浏览器**，度量误差为 0。此时 `F_w/F = 1.31` 只能是**高度估字号偏小 24%**（`1/1.31 = 0.76`），与字体度量无关。

自洽校验：严格正文的 bbox 字宽中位 = **12.0pt**（CJK 字宽=字号 ⇒ 真字号≈12pt）；而 `F_w` 中位 = 1.31×11.94 ≈ **15.6px = 12.2pt** —— 二者吻合，**证明 F_w 就是真字号，F 偏低约 24%**。

故「系统性 >1.2」在这里**不能**归因于「浏览器字体比印刷体宽」；主体是**字号估计误差**（0.72 常数偏小；等价于 `bbox_h ≈ 1.08×字号` 而非代码假设的 `1.39×`，正确系数约 **0.92–0.94**）。真正可能存在的字体度量差异被公式块的度量假象掩盖，本数据无法单独分离。

## Q7 左右两栏缩放是否一致（关键项）

来源：`stages/stages.css:341-371`（`.compare-wrap / .compare-pane / .origin-page-img / .canvas`）+ `stages.js:537-578`（`renderCompare`，`PANE_W = 460`）。

| 量 | 值 |
|---|---|
| `.compare-pane` 宽 | 460px |
| 左：`.origin-page-img` 宽 | `width:100%` → **460px** |
| 右：`.compare-pane .canvas` 宽 | `width:100%` → **460px** |
| 页宽 | 596pt；原卷 PNG | 995×1369px |
| **左栏 px/pt** | 460/596 = **0.7718** |
| **右栏 px/pt** | 460/596 = **0.7718** |
| 页面宽高比 | 821/596 = 1.3775；PNG = 1369/995 = 1.3759（差 0.12%，可忽略） |
| 阶段 0/2/3 画布宽 | 760px（与 `CANVAS_W=760` 一致） |

**结论：两栏使用同一个 px-per-point（0.7718），几何上完全对得上**，默认布局下左右对照是**可信的**（与前提中「若两栏缩放不同则误导」的担忧相反）。

**但有一个真实隐患**：右栏字号用**硬编码 `PANE_W = 460`** 换算成固定 px，而块框位置用百分比。当视口 < 约 980px 时，`.compare-pane`（`flex-shrink:1`）被压窄，两栏**同步等比缩小**（几何仍对齐），但字号是固定 px 不随之缩小 → 右侧文字相对块框**偏大**，才会出现「溢出/重叠」。即：**溢出症状是视口相关的**，宽屏（≥980px，两栏各 460px）下不成立。阶段 0/2/3 的 760px 画布同理。

## 汇总：决策价值最高的数字

1. 主导正文行高 **11pt**，正文簇 10–12pt 占 **63.9%**（616/964）。
2. 现行 `F = h×0.72`；正确系数应约 **0.92–0.94**（因 `bbox_h ≈ 1.08×字号`，非假设的 1.39×）。
3. 纯 CJK 行 `F_w/F = 1.31` → **字号被低估约 24%**，且这是**零度量误差**下的纯字号误差。
4. 普通文本（无 LaTeX，769 块）估算宽/bbox宽 中位 **0.67**，p99 1.03 → **普遍偏小，基本不溢出**。
5. 溢出 >1.1 的 75 块中 **68 块含公式**；无 LaTeX 子集只剩 **4 块**。
6. bbox 相交块对**全卷仅 9 对** → 块框重叠几乎不存在。
7. 多 span 行中 **90.3%** 的 span 高度不一致；行内 span 高差 p90 **13pt** → 行 bbox 高度不是字号代理。
8. 两栏 px/pt 均为 **0.7718**（左图 460px、右画布 460px / 596pt）→ **左右缩放一致**；仅窄视口（<980px）因字号硬编码 460 而失配。
