# P-1 · corrections 回放证伪（2026-11-02 晚）

**要回答的问题**（外部评审建议 ①，见 `docs/reviews/2026-11-02-外部评审-置信门控方案.md`）：
仓库里已有 **138 条人工核对过的真实缺陷修正**（`corrections/*.json`，`verified:true`）。
把这些修正**逐条拿掉**，现有信号能不能自己报警？
—— 能 ⇒ 置信门控有戏；不能 ⇒ 当场证伪。

**方法**：`tmp/p1-replay/replay.ts`。对每本有 `layout.json` 的册，用同一份输入跑两遍
`normalizeLayout → ruleStrategy.segment`，唯一变量是**是否应用 corrections**（受控 A/B）。
再对每条修正判断：拿掉它之后（a）该页题数是否变少，（b）该页所属编号组是否留下
**题号脚印**（缺号 / 回退 / 重号，即 §96 与 N7 的判据）。

---

## 结果

```
参与回放：136 条（光学 2 条无产物，跳过）

按「拿掉后是否改变题数」分：
  改变题数（结构性）    13 条  ┐
  不改变题数           123 条  ┘ → 136

结构性那 13 条里：
  ① 无修正状态下有题号脚印（缺号/回退/重号）  12   ← 结构尺子「有信号可报」
  ② 完全静默（少 2 题，题号序列毫无异常）      1   ← 红线级
     └ 物理_教材基础练 运动和力 p10 insert，组 ?|8

按修正类型 × 是否改变题数：
  insert（整行内容漏读，人工补回）  102 条 → 改变题数 **2** / 不改变 **100**
  replace（认错字，如 O→0）          21 条 → 改变题数 **0** / 不改变 **21**
  replace_text（补题号前缀/半行修补） 12 条 → 改变题数 **10** / 不改变 **2**
  split（拆块）                       1 条 → 改变题数 **1**
```

## 一句话结论

> **在 138 条已核对的真实缺陷里，只有 13 条（9%）落在「题数/题号」这一维上；
> 剩下 125 条（91%）——100 条整行内容漏读 + 21 条字认错——结构尺子原理上看不见。**

⇒ 外部评审的第 1、2、7 条**被数据证实，而且比它说的更严重**：
不是「共错看不见」这一个洞，是**主信号选错了维度**。

## 但同一批数据也指出出路

那 100 条「整行漏读」当初是怎么被发现的？——**文本域跨源比对**（整页 OCR / OXR / Word 对文字），
不是数题号。本次回放里也量到了这一点：结构性那 13 条中，**9 条在整页 OCR 文本里能直接找到那一行**
（⇒ §99 原理可报）、1 条找不到、3 条该书没有 OCR 文件。

⇒ 正确的架构不是「结构判据 + 一致性打分」，而是：

```
主信号：每道题都要有 ≥2 个独立文本源的证据（MinerU / OXR / 整页 OCR / Word）
        一致度 = 文本证据一致度，不是题号一致度
第二层：结构判据（题号脚印、§99、§102）—— 它只覆盖 9% 的缺陷面
```

**成本账（这一条被今晚的吞吐改口彻底改变了）**：

```
整页 OCR 实测 75–90 秒/页
  1 本 ≈ 15 页 ⇒ 约 20 分钟/本   ← 1 本/日 完全可接受
  旧口径 100 本/日 ⇒ 33 小时/日  ← 当时不可能，所以只能靠结构尺子凑
⇒ 「每本都跑全页 OCR 做文本域比对」从不可行变成可行，
   这才是 P-1 真正换来的决策信息。
```

## 已知偏差（不许当成结论）

1. **回放未注入 OCR 题号行**：`export-stages` 在切题前会先用整页 OCR 补题号行，
   本回放走 `segmentFromLayout` 等价路径，**没有这一层** ⇒ 「改变题数」的 13 条可能被高估
   （其中一些在没有 corrections 时会被 OCR 注入自己补回来）。
   修法：下一步带 `injectOcrQuestionLines/injectOcrFullTextLines` 再跑一遍对照。
2. **「有脚印」≠「会被判红」**：§99/§102 是登记表模式，历史命中可能已登记为已知。
   本次只证明「信号存在」，没证明「闸门当时会响」。
3. **样本偏倚**：138 条是「我们已经发现并修掉的缺陷」，不代表全部缺陷的分布
   （没被发现的那一类，很可能正是结构尺子看不见的那一类）。
   ⇒ 这个数只能用来**否证**（证明门控不够），不能用来**定标**。

## 对金标/标定方案的连带影响

- 金标的作用从「验每本书」收缩为一件事：**标定「文本证据一致度 → 真实正确率」这条曲线**。
- P-1 已经交出第一批**真实负样本**（138 个已知缺陷点，带页码/类型/是否改变题数），
  比构造负样本可信——评审的 ① 达成。
- 选金标书的原方案（一本公式密集 + 一本公式稀疏）**被数据否掉**：13 本公式占比 67%–91%，
  没有稀疏的那一本。见 `docs/BACKLOG.md` B-08 的更正。
