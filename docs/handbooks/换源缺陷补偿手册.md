# 换源缺陷补偿手册（OXR + 本地 V3 时代）

> 📍 交接导航：当前状态/风险/红线见 [docs/HANDOFF.md](../HANDOFF.md)（§9 为本轮交接正文）；
> 工程纪律见 [tasks/lessons.md](../tasks/lessons.md)；决策依据见 [docs/DECISIONS.md](../DECISIONS.md)（§114/§115）。

> **读者**：第一次接触本项目、但工程能力强的 Agent。读完你应能独立处置「换解析源/切源」带来的各类缺陷。
> **日期**：2026-11-20（M5/M7 实战沉淀）。**定位**：领域缺陷手册——不是工程纪律（那是 `tasks/lessons.md` L1–L15），
> 也不是决策史（`docs/DECISIONS.md`）或台账（`docs/BACKLOG.md`）；三者的交叉引用在 §5。
> **一句话总纲**：**换源不会一劳永逸。OXR+V3 消灭了 MinerU 的错，同时带来自己的缺陷面**；
> 每类缺陷都有稳定的「补偿位」（转换层 / 引擎判据 / 修正层 / 审计基线 / 展示层）。
> 先归因分类，再按选点原则落地——**禁凭猜测调参凑绿**。

## 1. 缺陷类型学（症状 → 根因 → 判据 → 补偿位 → 案例）

| 类别 | 症状（先看到什么） | 根因（哪一层） | 判据/特征 | 补偿位 | 案例 |
|---|---|---|---|---|---|
| **A 行框几何漂移** | 墨迹覆盖率审计暴涨（内容级「未覆盖」241–378 条/册） | 转换层合成行框：OXR 块按「均匀行高+字号高」造 bbox，与墨迹系统性错位 10–20pt（MinerU 是段落级大框，盖得住） | 数字暴涨**先怀疑尺子**：同页图只换块集即逐字复现两态 ⇒ 差异 100% 来自块集；题数/文本量不变 | **审计基线**按新口径单独标定（§62/§115），**不**改分类判据、**不**改合成框（改框=动显示几何，需独立决策） | B-54、DECISIONS §115、commit 3ebebc4 |

**归因口诀（先判后修）**：真丢（原卷有产物无）/ 伪影（碎墨装饰误判）/ 口径（尺子旧）/ 误报（判据错）——
**四者处置完全不同**；判据误报修判据、真丢补内容、口径重锁、伪影不动。拿不准标 `needs_review`，**别塞登记表**。

## 2. 选点原则：缺陷修在哪一层

| 层 | 影响面 | 用法 | 硬约束 |
|---|---|---|---|
| 转换层（`oxr-convert`/导出清洗） | 全部已切册 | 有确定形态规则的清洗/剥壳/丢弃 | 小步+TDD；**抽 2 册逐字节回归对照** |
| 引擎判据（normalize/patterns/rule-engine） | 所有该源形态输入 | 结构性判定修正 | 必须加**源形态守卫**（新逻辑只对新源生效；旧产物逐字节不变，用测试锁） |
| 修正层 `corrections/` | 指定册 | 逐条人工核对的内容修补/退休 | 逐条回原卷，`verified`+`evidence`；退休留 `retired` 记录 |
| 审计基线（audit-*） | 判定门 | 口径变化时重锁 | 先证非真缺陷；DECISIONS 登记；容忍带不动 |
| 展示层（stages/final/viewer） | 显示 | 最后手段（缺图降级、占位隐藏） | 展示层不 import 引擎；DOM 文件不写 `@ts-check`；缺图占位默认不可见 |

## 3. 换源/换解析 SOP（标准作业顺序）

1. **备份**：切前快照 + sha256 清单（放 `tmp/<任务>/backup/`）。
2. **血缘标记**：记录每册 `layout.json._backend`（`pipeline`=MinerU；无字段=被切源/处理过——`lessons L7`）。
3. **逐册切换+重导出**（两参必传，显式路径；禁默认输入）。
4. **双向对照**：内容（逐页行集合）、题数（逐题）、块级 diff（added/removed/moved 计数）、抽样逐字节。
5. **归因分类**：§1 口诀，逐类出判定+证据（ffmpeg 裁原卷，R1–R7）。
6. **按选点修**：§2；每条修复带测试锁。
7. **复跑门+审板**：审计门复跑 + 成品页抽样截图三通道（DOM 预检→像素→目视）。
8. **台账**：BACKLOG 条目（B-xx）+ 必要时 DECISIONS §；数字必须实跑（禁抄）。

## 4. 换源类红线速查

- **不为淘汰物补产**（将被切换掉的旧源缺陷不修），**但窗口期内修内容错误**（§114：错的东西修、没有的东西随切换）。
- 判据最严 **AND** + 反误杀守卫 + **可核对记录**；「拿不准不滤/标 needs_review」。
- 基线重锁 ≠ 掩盖：先证「非真缺陷」，带证据+DECISIONS。
- 中文卷名 URL 一律 `encodeURIComponent(dirName)`（手写百分号编码打错字=假缺陷，B-51）。
- 产物是快照不是事实：任何数字实跑（`lessons L7`）；`tmp/` 证据目录跟任务走。
- 工作流/长任务：任务按「会断」设计（两阶段交付：判定+红测试先提交，再修复）；撞轮次上限读 `tmp/` 落盘续做，不重跑。
