## 六、这次演进里沉淀下来的三件方法论

```
① 度量先自证
   「先出数、后自证」出了三次错（边对边相减 / 未排除坐标尺度 / 同源数据当裁判）
   ⇒ 报数之前，先用另一种方式验一次这个度量能不能区分真伪

② 同源数据不能互相当裁判
   content_list.json 与 layout.json 是同一次解析的两套输出，错得一样
   ⇒ 唯一独立来源是原卷页图（技能 screenshot-evidence）

③ 产物不是事实
   data/ 全是快照，questions.json 只代表"某次运行"
   ⇒ 说"代码现在的行为"必须重跑（npm run preflight → daily → 再统计）
```
