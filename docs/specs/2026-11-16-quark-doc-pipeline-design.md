# 夸克 DOC 驱动流水线（v1 设计）

- 日期：2026-11-16
- 状态：**待用户批准**（未批准前不写任何产品代码）
- 前置调研：`.workbuddy/memory/2026-11-16.md`（含全部实测数字）

## 1. 一句话

不再用 MinerU 的版面/坐标去切题，改为**直接吃夸克扫描王导出的 DOCX**：按分节符还原页、
按页眉还原页码、按段落状态机切题、按「节 → 栏目 → 序号」三级锚点配答案。

## 2. 为什么换（用户口径，三条全要）

1. 现有几何判据（洞 / 配对）消耗大、结论反复，想摆脱；
2. 金标准转写靠人工看图，想省钱省时间；
3. 认为夸克扫描的识别质量可接受。

## 3. 范围

**首期切片（2026-11-16 14:39 用户定案）**：《物理_教材基础练 电路》，取其中 8–10 题。

选它的理由（第一性）：**这是唯一 PDF、DOCX、原卷页图、MinerU 旧产物、金标准五样齐全的一本**。
M0 实测发现「高考必刷题合订本正册」的 PDF 不在 `books/` 下，独立裁判缺席；
而《电路》在 `data/out/物理_教材基础练 电路/pages/page-NN.png` 有原卷页图，
可直接按页裁图核对公式和题干，不必接受"没有独立裁判"这个前提。

**非目标（本期不做）**：全书 30 册批量、显示层改版、MinerU 流水线删除、OCR 源替换。

## 4. 目标 / 非目标 / 反目标

- 目标：给定一份夸克 DOCX，产出**可追溯**的结构化题目 JSON：每题知道自己在哪一页、哪些段落、
  答案是什么、哪些地方不确定。
- 非目标：100% 免人工。本期接受「不确定就标出来」。
- **反目标**（技术上成功也必须算失败）：
  - 出题数量对得上，但题目内容被静默改写/丢公式；
  - 页码是自己编的，不是原书印的；
  - 不确定的地方被"猜一个最可能的"填上。

## 5. 路线取舍

| 路线 | 做法 | 收益 | 代价 | 结论 |
|---|---|---|---|---|
| A 预填器 | DOC 只给人工金标准做草稿 | 最便宜、当天可用 | 不解几何之痛、不解决配答案 | 不选（本轮三条动机都指向生产线） |
| B 双轨并行 | 新线独立成型，旧线保留当对照 | 零回归风险、可 A/B 出证据 | 短期两套产物 | **选它** |
| C 直接替换 | 删掉 MinerU 线，DOC 单源 | 最干净 | 失去唯一独立对照，出错无法归因 | 不选（违反"判据与实现不同源"红线） |

选 B 的第一性理由：新路的失败方式是**静默**（OCR 错字、公式结构丢），
而抗静默的唯一手段是**第二个不同源的读数**。旧管线产物已经存在，留着它成本为零。

## 6. 架构（阶段与产物）

```
data/inbox/<册>.docx
  │
  ├─ S0 解包       word/document.xml → 段落流 + OMML 树 + 图片清单
  ├─ S1 页还原     用页码标记（页脚为主）重建页 → 段 ⇄ 页 映射
  │                ⚠️ 不可用 w:sectPr 序号当页号（见 §11：562 节 ≠ 274 页）
  ├─ S2 噪声剥离   页眉页脚 / 装饰重复 / 页签粘附
  ├─ S3 公式还原   OMML 节点 → LaTeX（结构级，不取文字层）
  ├─ S4 切分       章节 → 栏目 → 题号 → 题干 / 选项 / 小问
  ├─ S5 答案匹配   答案册同构切分 → 三级锚点配对
  └─ S6 交付       questions.json + 页级导览 + 未决清单
```

产物落 `data/out-doc/<册>/`，**不写 `data/out/`**（那是 MinerU 线的快照，混用会造成归因混乱）。

## 11. M0 实测结论（2026-11-16，三路只读审计）

### 11.1 页映射：**假设被推翻** —— 节 ≠ 页

- 正册 `w:sectPr` **562** 个，印刷页 **274** 个，节页比 **2.03**；只有 **31.8%** 的页是单节。
  分节切出来的不是「页」，而是排版切片：栏目条 / 正文块 / 页码行 各自成节。
- 一页的典型组成（p5）= 节23(栏目条 62 字) + 节24(正文块 966 字) + 节25(空节重复页码)。
- **页码印在页脚，不在页眉**：562 个 header 部件里仅 49 个非空，全是「刷基础…计划用时·答案D…」栏目条，
  **0 个含页码**。答案册那套「页眉页码」规律**不能外推**到正册。
- 重建后页码 **1–274 连续**（另有前言 3 页标 Ⅱ/Ⅲ/Ⅳ、目录首页标阿拉伯 1，混用两套数字体系）。
- 原始解析曾出现 4 处断号（95/165/169/203），逐条查证全部是**导出丢字或粘连**，不是缺页。
- ⇒ **S1 的算法改为：页脚页码 + 段落级页码行 + 单调守卫重建页，禁用 sectPr 序号作页号。**

### 11.2 公式：节点层没问题，**字符层才是雷**

- 7610 个 `m:oMath`（正册 1720 / 答案册 5890），`m:oMathPara` = 0 ⇒ 全是行内碎片，无独立显示公式。
- 只用到 **9 类节点**（`m:f` 6411、`m:sSub` 8357、`m:sSup` 3021、`m:sSubSup` 1060、`m:rad` 1384、
  `m:d` 1188、`m:acc` 67、`m:limUpp` 2、`m:eqArr` 1）；`m:nary`/`m:func`/`m:m`/`m:groupChr` 全为 0。
- 原型转换器 **7610/7610 成功、未知节点 0**；必须靠猜的仅 **6 个（0.08%）**。
- 四类必踩的字符陷阱：
  1. `m:d` 省略 `begChr/endChr` 时 OOXML 默认就是 `()`，占 1168/1188 ⇒ 当作"无括号"会**静默丢 1168 处括号**；
  2. `△`(U+25B3) 与 `Δ`(U+0394) 混用（29+250 / 17+257），前者不是希腊字母；
  3. `∘`(U+2218) 原文当度符号用（`sin37∘`），直出报错；
  4. `~` 在 LaTeX 是不换行空格（`t1~t2` 静默变 `t1 t2`）、`%` 是注释符（不转义会**吞掉整行后半句**）。
- **覆盖盲区**：另有 **165 个段落把公式当普通文字打在 OMML 之外**（如 `mg/P₀=TA,`、`v =√v₀+(g`），
  任何结构级转换都碰不到 ⇒ 这部分只能靠字符启发式检出后标 `needs_review`。

### 11.3 噪声：三条形态，机检难度完全不同

| 形态 | 真相 | 命中 | 误伤 | 处置 |
|---|---|---|---|---|
| 整行重复 | **不是文本重复，是结构重复**：175 个 `mc:AlternateContent` 使每个浮动文本框的 Choice/Fallback 各存一份 | 163 对（158 对属此因） | 按文本相等去重会误删 **5 对真数据**（图注「逆时针/顺时针」、表格 0.33×3） | 丢 `Fallback` 分支，零误伤 |
| 页眉页脚 | 两条窄模板即可全覆盖：`^答案及解析\s*\d{1,3}$`（92）、`^\d{1,3}\s*高考必刷题\s*物理$`（150） | 242 条 | ≈0 | 模板化删除；但**删后是否重连须按句末标点判断** |
| 页签粘附 | 段末同章名**连写 ≥2 次**才是页签（正文不可能连写两遍章名） | 47 段 | **0** | 可自动化；单写（21+13）与段首（4+1）实测 **39/39 全是假阳性**，一律不删只记候选 |

- **召回器陷阱**：用「短段 + 含 1–3 位数字」找页眉会得到 2329 个候选，其中 2087（89.6%）不匹配任何模板
  ⇒ 这个召回器只能用于**发现**，绝不能用于**删除**（会误删选项标签与表格数值）。
- **真正的缺口在召回之外**：正册偶数页 2–270 共 135 个页眉位，DOCX 里只存在 **59** 条，
  76 条页眉在文本中根本不存在 ⇒ 页重建不能只依赖页眉。
- **页眉会切断题干**：正册段 5360 把第 5 题劈成 5357 与 5363 两段 ⇒ 处理不当会让题数虚增。

## 12. M0′ / M1 / M2 实测（2026-11-16）

### 12.0 统一段落编号口径（全队硬约束）

`w:body` 深度优先遍历；每个 `w:p` 只取自身直属 run 的 `w:t`，**不并入嵌套文本框内的 w:p**；
`mc:AlternateContent` 只取 `mc:Choice`、丢弃 `mc:Fallback`；空段占号，从 1 起。
该口径下正册 **7979 段**、答案册 **6524 段**。此口径能消掉 Choice/Fallback 双写，
是后续的唯一口径；不同口径报出的段号一律作废。
（M0′ 两个审计曾用不同口径报段号 —— 5570–6242 vs 2681–2964 —— 是本次新增这条硬约束的直接原因。）

### 12.1 M0′ 结果

- 电路章 = 第九章恒定电流，正册正文段 **4538–5072**（段 5073 起磁场）。
- 页码标记只在 footer（header 含数字 = 0），且**覆盖不全**：23 个 sect 中 12 个 footer 为空。
  正文仅检到 `107@段4604`、`111@段4791`。⇒ **不能靠页码标记单调守卫重建页**，
  缺号处必须用原卷页图锚定。可确认印刷页 **107–119 共 13 页**，13 张 `page-NN.png` 一一对应
  （已裁验 page-01=107、page-07=113、page-13=119）。
- 噪声（本册专用，与另一本书不同）：`mc:AlternateContent` 电路章 93 个、文本 100% 相同 ⇒ 取 Choice 单侧；
  页眉是章名 +「基础双练 教材基础练」，最长 17 字，**不会劈开题干**；页签双写仅 2 段且零误伤；
  另一本的 `^答案及解析N$` 等模板在本册 **0 命中**，不得复用。
- 图片性质：电路章 `w:pict`=93 全是文本框（`v:imagedata`=0）、`w:drawing`=148 含 55 个 `a:blip` 是插图；
  `m:oMath`=189 ⇒ 公式确实是 OMML 不是图片，在此章再次证实。
- 答案册锚点：电路章段 **1791–2059**。栏目 `教材知识54/55/56/57`、`教材实验10/11/12/13`、
  `大单元素养聚焦` 两书编号与题数一致；题号每栏目内从 1 重数 ⇒ **三级锚点条件成立，不是无条件成立**。
  破坏唯一性的四类情况见 §12.4 的排除清单。

### 16.3 公式为什么必须转换

- DOCX 里的公式是 **OMML**（Office Math Markup Language），Office 私有 XML，**只有 Word/WPS 能渲染**。
- 浏览器不认识 OMML。「直接复制」在 Word 内可行，跨到网页/JSON 不可行——必须换成浏览器能读的表示。
- 本轮改用 **MathML**（W3C 标准，现代浏览器原生渲染，不依赖 CDN/第三方库），
  与 OMML 结构几乎一一对应（`m:f→mfrac`、`m:rad→msqrt`、`m:sSub→msub`…），比 LaTeX 更保真。
  转换器：`tmp/docpipe-m4/omml2mathml.py`，未知节点输出显式标记，不静默。
- **上一版显示成「乱码」的真实原因**：我把 LaTeX 源码直接当纯文本输出（`$I=\frac{...}$`），
  根本没有渲染。这是展示层遗漏，不是转换错误。
