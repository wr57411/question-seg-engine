## 1. 三条铁律

- **铁律一：先写判据，再截图。** 判据没写的项，截一百张也看不见。
  每张截图前先答：这张图我要验证哪几条？通过长什么样？
- **铁律二：缩略图只用于找异常，判定必须看原尺寸。**
  联系表（contact sheet）扫一遍找可疑，再裁到 100% 看。
  「✓ ✓」就是在 470px 缩略图里没数出来。
- **铁律三：每类问题除了查「有没有」，必须查「几个 / 在哪 / 顺序」。**
  有没有公式 ✅ ≠ 公式在正确位置 ✅ ≠ 公式只有一个 ✅。

## 2. A 节：通用清单（任何网页 / UI 交付都适用）

| # | 检查项 | 怎么查 | 通过判据 |
|---|---|---|---|
| A1 | 不是白屏 | 截图 + `--dump-dom` | 主体内容区有文字，DOM 中目标容器非空 |
| A2 | 运行时无报错 | Chrome `--enable-logging --v=1`，或注入 `window.onerror` 收集 | 0 条 uncaught error |
| A3 | 图片真的加载了 | `evaluate(el => el.complete && el.naturalWidth > 0)` | 所有 `<img>` 为 true，无破图图标 |
| A4 | 字体没回退成方块 | 放大截图看中文/符号 | 无 □ 豆腐块，公式符号正确 |
| A5 | 无横向溢出 / 裁切 / 重叠 | 截图 + `document.documentElement.scrollWidth <= clientWidth` | 无横向滚动，文字不出框 |
| A6 | **局部放大看** | 裁关键区域到原尺寸（非缩放） | 单字符级正确：无重复符号、小数点、上下标、括号配对 |
| A7 | 空状态不留空壳 | 造一个「无数据」场景截图 | 空容器无残留边框/空白块（`:empty` 已处理） |
| A8 | 极端内容不破版 | 最长文本、最多选项、字段缺失各截一张 | 布局不塌、不溢出、不遮挡 |
| A9 | 交互后状态 | 点击/切换前后各截一张 | 切换后视觉与数据一致（不残留上一态） |
| A10 | 打印/导出真实生效 | **实际导出 PDF 并逐页看**，不能只看 CSS | 页数与预期一致，无重复页/空白页，控件已隐藏 |
| A11 | 多视口 | 手机宽（390）、平板、桌面各一张 | 均无溢出，字号可读 |
| A12 | 与参照物并排 | 截图必须与原稿/设计稿**同屏并列** | 能逐条指出「一致 / 不一致」，不是单图自评 |

## 3. B 节：本项目特有清单（DOCX→题库→展示/打印）

### B-1 内容存在性

| # | 检查项 | 怎么查 | 通过判据 |
|---|---|---|---|
| B1 | 公式渲染成真数学式 | 截图放大 | 真分式/根式/上下标；**不是** `$...$`、不是空、不是方块 |
| B2 | 公式数量对得上 | 逐题数 `optionsHtml` 中 `<math>` 个数 vs 源段 `m:oMath` 个数 | 两者相等（差额须逐条解释） |
| B3 | 插图存在 | 题卡内有 `<img>` 且 naturalWidth>0 | 原卷有图的题，产物必须也有图 |
| B4 | 插图不是废图 | 逐张看图 | 非破图、非白块、非邻栏残留（串栏算不合格） |

### B-2 位置与顺序（最容易漏的一层）

| # | 检查项 | 怎么查 | 通过判据 |
|---|---|---|---|
| B5 | 图的**位置**符合原卷 | 截图看 DOM 顺序 | 题干 → **图** → 选项 → 答案 → 解析（图不得落到解析后） |
| B6 | 图的**环绕方式** | 与原卷并排 | 原卷为文字绕排时，图应 `float` 在题旁，而非独占一行 |
| B7 | 题号 / 页码标注 | 逐题核对 | 与 M2 独立扫描的页码、栏目-序号一致 |

### B-3 边界与噪声（本册易错点，实测过）

## 4. C 节：截图**查不到**的，必须换度量

| 问题类型 | 为什么截图查不到 | 该用什么 |
|---|---|---|
| 页数 / 用纸量 | 「浪费纸」不是视觉缺陷 | 导出 PDF 数页：`pdftoppm -png x.pdf p && ls p-*.png \| wc -l` |
| 答案配对是否正确 | 画面正常但语义错 | 独立源（答案册）三级锚点对账 |
| 题数对不对 | 少一题画面看不出来 | 整章独立正则扫描，与切分器**不同实现** |
| 文本是否漏字 / 幻觉 | 读起来通顺 | 字符级 diff（源段 vs 产物） |
| 性能 / 体积 | 不属视觉 | 字节数、加载耗时 |
| 无障碍 / 对比度 | 需量化 | axe / contrast 工具 |

**规则**：凡是指标型的验收项（页数、数量、体积、耗时），一律不进截图清单，另立命令验收。

## 5. D 节：执行流程（避免「截了但没查出」）

1. **写判据表**：本次要验哪几条，每条的通过长什么样 → 落到 `checks.json`。
2. **全量截图**：固定命名 `q1.png … qN.png`，脚本可复跑（`docpipe/shot-compare.sh`）。
3. **两步看图**：先联系表扫异常 → 可疑项裁原尺寸确认。**缩略图不下结论。**
4. **并排对照**：涉及「像不像原卷」的，必须左原卷右产物同屏。
5. **指标另测**：页数、题数、字数用命令跑，不靠看。
6. **改一处必回归**：任何样式/渲染改动后重跑全量截图（勾号、空框都是叠加类改动引入的）。
7. **每条 PASS 写依据**：图号或命令，禁止只写「已检查，通过」。

## 6. 一页速查（打印贴墙）

**截图前**：判据写了吗？要查「有没有 / 几个 / 在哪 / 顺序」四项吗？

**截图时**：
- [ ] 白屏？破图？豆腐块？
- [ ] 横向溢出、文字被裁、元素重叠？
- [ ] **公式是真分式吗**（不是 `$...$`）？数量对吗？
- [ ] **图在题干旁边吗**（不是解析后面）？
- [ ] 题干尾部有没有混进「变式N / 第N讲 / 页码 / 上课认真听」？
- [ ] 四个选项各自成行吗？编号齐 A–D 吗？
- [ ] 正确答案**只有一个勾**、只在正确项上？
- [ ] 空容器有没有留空壳边框？
- [ ] **放大到原尺寸**看过关键区域了吗？

**截图后**：
- [ ] 导出 PDF 数过页数了吗（≤ 原卷）？
- [ ] 交互开关开/关两个状态都截了吗？
- [ ] 每条 PASS 都写了依据吗？

**别指望截图**：页数、答案对错、题数、漏字 —— 这些用命令和数据对账。
