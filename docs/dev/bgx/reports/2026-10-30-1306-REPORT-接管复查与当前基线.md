## 4. 缺口清单

### G01 [P2 / 已确认缺陷] 6 册 `meta.json` 体检摘要过期，成品页头部与 `/api/docs` 显示错误题数

- **证据**：§3.2 对照表；`/api/docs` 返回 `"questions": 31`；成品页头部截图。
- **触发与影响**：任何人打开这 6 册成品页/读 API 即触发；`needsReview`、`missingNumberGroups` 也可能同步过期。
- **建议（三选一或组合）**：
  1. **先修数据**：对 6 册跑
     `npm run daily -- "data/out/<docId>" --id "<docId>" --meta-only`
     （离线、不动产物；`importedAt` 会更新为刷新时刻）。
  2. **加门**：在 `check` 或单测里比对 `meta.stats.questions` 与 `questions.json` 长度、
     `meta.stats.pages` 与 `stages.pages`，不一致即红（反向验证：故意改坏一册必须红）。
  3. **治根**：`stages:export` 完成后自动重算 meta（或让导出命令附带 `--meta-only`）。
- **规模**：小。**边界**：写 `data/out`（git 忽略），不涉及仓库与页面逻辑。
- **依赖**：无。
