# ATTRIBUTION — 错误归因基线（先怀疑谁）

> **用途**：每次判断"这个错是谁的"之前，先查本表。目的是防止把**机器缺陷**记成**出版物缺陷**。
> 本文件是**先验**，不是结论：先验决定你先查哪一头，查完仍要拿证据。

---

## 0. 一句话原则

**正规教辅出版物不会犯排版/编号类低级错误。** 它的编辑流程会放过个别错字，
但绝不会放过"题号跳号""选项缺一个""题目串行"——那是会被退回重印的错误。

⇒ **凡是"题号 / 选项 / 段落归属 / 栏目结构"出问题，一律先怀疑我们的流水线，不怀疑原书。**

---

## 1. 出版物**会**犯的错（可以归因给原书）

| 类型 | 例子 | 判别难度 |
|---|---|---|
| 个别错别字 / 形近字 | 「反亥姆霍兹」印成「反亥姆霍滋」 | 中（需页图直读） |
| 题目本身的逻辑或答案错误 | 题干条件矛盾、答案与选项对不上 | 高（要懂物理） |
| 公式排版小瑕疵 | 上下标错位、分式线缺失 | 高（需与原图比对） |
| 图表标注错位 | 图注指错位置、编号与正文不符 | 中 |
| 时效性/版本差异 | 旧版页码、旧教材引用 | 低（属正常现象） |

**共性**：都是**局部、单点**的错误，不影响整体结构。

## 2. 出版物**不会**犯的错（禁止归因给原书）

| 类型 | 一旦出现，必是我们的问题 |
|---|---|
| 题号跳号 / 缺号 | 如 1,2,4 —— 原书不会漏印第 3 题 |
| 题号重复 | 同一节出现两个「3」 |
| 题号从非 1 开始（非栏目重编） | 除非该栏目本就重编号，否则是漏切 |
| 选项缺项（A、C、D 无 B） | 排版会整组检查 |
| 题干从中间开始 / 被截断 | 上游折行或切分错误 |
| 题目串到别的小节 | 栏目/节边界识别失败 |
| 栏目结构错乱（刷基础/刷易错 混在一起） | 分节识别失败 |

**共性**：都是**结构性**错误。结构性错误必定来自"解析 → 归一化 → 切分"链路。

---

## 3. 下结论前必须满足的三条（缺一不可）

想写"原书这里缺/错"之前，逐条打勾：

- [ ] **两源一致**：至少两个**互相独立**的源都显示同一现象
      （例：Word 扫描件 + 项目整页 OCR；或原卷页图 + OCR）。
      ⚠️ 同一个源跑两遍不算两个源。
- [ ] **已排除上游识别错误**：确认不是 MinerU 认错字、折行、丢块。
      最快做法：查 `ocr-page/pNN.txt`（项目整页 OCR）同一位置的原文。
- [ ] **页图直读**：至少看过一处原卷页图，眼见为实。

三条缺一条，结论只能写成"疑似"，不能写成"原书如此"。

## 4. 遇到 §2 现象时的排查顺序

```
题号/结构异常
   ↓ ① 原卷页图：书上到底印了什么？（`data/out/<doc>/pages/page-NN.png`）
   ↓ ② 项目整页 OCR：`ocr-page/pNN.txt` 同一位置有没有这行？
   ↓ ③ MinerU layout：块首是什么？题号在不在块首？
   ↓ ④ 归一化（normalize）：这行有没有被折行/迁移/合并？
   ↓ ⑤ 切分（rule-engine）：判据为什么没认？（直接调 matchFirstLine 试）
   ↓ ⑥ 展示层：只是没显示，还是数据里真没有？
```

**先看①②再往下**：这两步能立刻区分"原书问题"与"上游识别问题"，
成本只有一次 `grep` 加一次页图，比任何猜测都快。
