## §3 预计可验收的子目标清单（长程防遗忘）

> 每条 = 可验收判据 + 跑法 + 主导方。管家自主项做完勾选附证据；human gate 明确标出。
> 设置子目标的目的：把「95% 坐标 + 可信交付」拆成可独立验收的小步，全程管家主导、不遗漏。

- [ ] **S1 表格结构稳健性**：≥5 页含表格页（含插图表/合并格/纯文本表）V3 结构正确率 ≥95%
      （cell 数/列数/合并格对齐真值抽检）。跑法：`run_ppstruct.py` 逐页 + 真值裁图对照。主导：管家。
- [ ] **S2 放置实现（A 内联 + 表格 HTML）**：`renderPaper` 对 `coordSource:"crop"` 行内联裁图
      （native 尺寸、超栏宽才缩放，实测缩放后仍≥19px）；表格行渲染 V3 `pred_html`。
      验收：成品页截图目视可读、无 overflow:hidden 裁切、不丢内容。依据：§1 放置实验（6616 裁图）。主导：管家。
- [ ] **S3 开旗标小试对照**：p76/p127 开 `truncationCropFallback` vs 基线，配对数不降、noBand→0、
      无跨行垃圾（抽检裁图）。跑法：`audit-giant-crop.ts --crop-fallback`。主导：管家（行为变更，先小试）。
- [ ] **S4 全册坐标正确率 ≥95%**：开旗标后复跑全册，复合/统一墨迹裁判均 ≥95%。
      跑法：`audit-giant-crop.ts --all --all-noband` + `audit-formula-ink.ts`；判据 target95Met。主导：管家。
- [ ] **S5 逐页截图审板**：全册成品页逐页截图，无裁切/丢内容/串位。跑法：现有截图审板流程。主导：管家。
- [ ] **S6 真机验收（human gate）**：iPad 真机 Safari 长按/滚动/键盘顶起；手机正文可读性（5.67px 问题）。
      主导：**用户**（管家备局域地址+验收清单）。
- [ ] **S7 挑题组合改名/删除**（用户优先级 1，独立支线）：管理界面支持组合改名/删除并显示影响题数。
      主导：管家；依据 `docs/plans/2026-10-30-pick-classify-workflow.md`。
- [ ] **S8 答案跨书错配修复**（独立支线）：同系列白名单配对，修前教材基础练答案不可信。主导：管家。

**验收总门**：`npm run check` 全绿 +（显示层改动）S5 逐页截图审板过 + S6 真机（human）。
「后台数字达标」≠「页面看得见」≠「没被裁掉」。
