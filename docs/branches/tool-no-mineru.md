## §1 分支目标（一句话）

**把 MinerU 换掉**（分支名 `tool-no-mineru` 即目标）。MinerU 一身兼两职「读字 + 定位」且**漏行**，
本分支把两职拆开各自换源：

```
读字（内容）  MinerU ──► OXR                 不漏行
定位（坐标）  MinerU ──► 墨迹带真值 ＋ 本地 PP-StructureV3 行框吸附
                          巨带挤掉的行 ──► 裁小截图内联补（A 内联）
表格          MinerU(损坏) ──► 分流：纯文本表→V3 HTML / 含图含公式→整表截图 / 无边框索引→守卫跳过
```

**验收总目标**：全册 ≥95% 行坐标正确（独立裁判）＋ 成品页可信交付（不丢内容/不裁切）＋ 真机可用。

## §4 长程工作流（Workflow Tool MCP）

用 `workflow_tool` MCP 驱动本分支长程目标，管家主导、按节点推进、`hole` 留白动态续写。

- **驱动方式**：`workflow_start` 编译启动 → 返回任务 → 管家用子代理执行 → `workflow_next` 交回；
  到 `hole` 停下，按最新发现续写下一阶段（= §5 重规划）。进程重启用 `workflow_resume` 接回。
- **种子拓扑**：质量门（`npm run check`）→ S1 表格扩大验证 → tail hole「决定放置实现与开旗标路线」。
  代码编辑阶段（N9 起）在 hole 里按 S1 结果设计，不预先猜拓扑。
- **runId**：`wfrun-95fed79d-17ee-48bd-b090-89b8e4b68ce1`（2026-11-13 启动；2026-11-20 **completed**：质量门✓→S1✓→hole 续写放置流水线→N9 实现✓→N10 小试✓→N11 全册✓→N12 审板✓→返回 BranchReport）
- **自主约束**（用户 2026-11-13 指令）：用户不在电脑边 ⇒ 工作流全程自主、不含需用户插手/反复迭代步骤；N13 真机 human gate 移出阻塞路径，只进报告 notCovered。hole 续写以 RETURN（BranchReport）收尾，不再开阻塞留白。
- **脚本草稿**：workflow_start 未返回 draft 路径；有效脚本随 hole 填充增长，`workflow_status`/`workflow_resume` 可接回。
- **门命令**：`npm run check`（typecheck + typecheck:viewer + test + 审计链 + check-stamp）；
  坐标验收 `tsx scripts/audit-formula-ink.ts`；巨带对照 `tsx scripts/audit-giant-crop.ts --crop-fallback`。
